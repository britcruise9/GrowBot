# Body prints (growbot_diy_v1_r01)

The current print set, same files served at [growbot.dev/build](https://growbot.dev/build):

- `growbot_diy_leg_v1_r01.stl` (print 2)
- `growbot_diy_body_v1.1_r01_beta_01.stl`
- `growbot_diy_backplate_v1_r01.stl`

Plain PLA, no supports. Legs screw onto the servo horns, no glue.

No printer? Use the [cutout template](../cutout-template.html) at 100% on paper and build from any stiff material.
