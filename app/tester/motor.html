① Check the legs

Run these 2 steps if something looks off.
Step 1 · which leg
LEFT and RIGHT are the robot's sides, so LEFT is on your right when you face its screen. Tap each button: only that leg should move, and it should swing down toward the screen, the way GrowBot stands up.
Other leg moved? Switch off and swap the two servo plugs (build guide step 04, part 4D). Correct leg, but it went up and away from the screen? Check that servo is fitted with its shaft pointing outward (step 04, part 4B). Both are wiring fixes, so there is nothing to set here. On an ESP32 build, swap the two pins in GPIO_PINS instead of the plugs (ESP32 guide step 05).
This phone still has leg directions saved by the old sweep test (). GrowBot and Move now use the stock leg directions by default. Older walk pages, the Custom agent tab and stockdir=0 links can still use these saved directions. Reset them for those paths only if this robot follows the stock build. Trims stay as they are.
Saved left/right swap: OFF
A software swap, only for robots already set up with it. The fix is to swap the two servo plugs, then turn this OFF. While it is ON, the forward walk, gentle spin, face follow and get-up stay off.
Step 2 · straighten
Phone on the robot? Take it off first. Lay the robot face down, then tap Hold legs up. This puts both servos at 90°.
Look at it from the side. Tap − or + until the near leg hides the far one and both point straight up.
