# Domain Docs

GrowBot uses a single-context domain layout.

Before product work, read `CONTEXT.md` and any relevant decision records in
`docs/adr/`. Use the glossary vocabulary in specifications, module interfaces, tests,
and user-visible copy. If a proposed change contradicts a decision record, name the
conflict rather than silently overriding it.

The public robot/reference stack and the hosted creature are related but not identical.
Do not infer hosted frontend or backend behavior from this repository when the source
is absent.
